# Tivorah web workspace instructions

Before designing or changing any Tivorah mobile or web UI, read and follow `../AGENTS.md` in full. Its UX laws, accessibility thresholds, responsive rules, data-state requirements, and design review checklist are mandatory. When a conflict exists, use the priority order defined in that file.

Preserve user changes and follow the commands, architecture, and conventions documented in this repository's README and package scripts.
